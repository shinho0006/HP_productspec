# 신호시스템 제품사양검색 (공개용 & GitHub Pages 배포)

신호시스템(SHINHO SYSTEM)의 제품 사양 검색 및 인터랙티브 주문 코드 구성기(Product Configurator) 공개용 정적 웹 애플리케이션입니다.

---

## 🔒 보안 및 데이터 안전성 (공개용 특화)
1. **내부 공급가 원천 삭제**: 주대리점가, 최소판매가 등 사내 민감 데이터는 데이터 추출 단계에서 1바이트도 남기지 않고 원천 배제되었습니다. (오직 소비자가격만 노출)
2. **OEM / ODM 모델 완전 제외**: 중분류 및 소분류가 OEM/ODM인 모델과 카테고리는 완전히 필터링되어 목록에 나타나지 않습니다.
3. **사내 파생 품목 리스트 제거**: 4,700여 개의 사내 내부 관리 품목코드를 노출하지 않고, 고객이 직접 조합할 수 있는 주문 사양 코드만 제공합니다.
4. **100% 무서버(Serverless) 독립 구동**: 외부 데이터베이스나 NAS 연결 없이, `web/product_data.js` 번들 하나만으로 브라우저에서 독립 작동합니다.

## 🚀 GitHub Pages 배포 방법

GitHub Pages를 통해 무료로 웹에 공개하여 테스트할 수 있습니다.

### GitHub Pages 배포 설정
1. GitHub 리포지토리(예: `shinho0006/Shinhosystem_hp_spec`)에 소스 코드를 푸시합니다.
2. 깃허브 리포지토리의 **Settings(설정) ➡️ Pages** 로 이동합니다.
3. **Build and deployment** 항목에서:
   - Source: `Deploy from a branch`
   - Branch: `main` (또는 `master`)
   - Folder: `/web` 선택 후 **Save** 클릭
4. 저장 후 약 1분 뒤 생성되는 웹 주소(`https://<계정명>.github.io/<리포지토리명>/`)로 접속하면 `web/index.html` 메인 화면으로 즉시 연결됩니다!

## 🔄 최신 엑셀 데이터 동기화 & 원클릭 배포 (로컬 PC)
엑셀 파일(`제품DB.xlsx`)의 가격이나 사양이 수정되었을 때:

1. **`update_db.bat` 파일을 더블클릭**하여 실행합니다.
2. 자동으로 보안 필터링을 거쳐 `web/product_data.js`가 최신 상태로 재구축됩니다.
3. 자동으로 깃허브(`git push`)까지 완료되어 GitHub Pages 웹 화면에 최신 사양과 가격이 즉시 반영됩니다!

*(수동 빌드만 원하실 경우 기존 `build_hp.bat`을 실행하셔도 됩니다.)*

## 💡 주요 기능
- **실시간 주문 사양 코드 조합**: 입력(INPUT), 출력(OUTPUT), 전원(POWER), 옵션(OPTION) 선택 시 주문 코드가 실시간 자동 조합됩니다. (예: `SHN-ISO-4N1-W`)
- **실시간 소비자가격 계산기**: 기본 소비자가격에 선택된 각 사양의 추가 옵션금액이 실시간 합산 계산됩니다.
- **사양 원클릭 복사**: [사양 복사] 버튼을 누르면 완성된 모델명, 주문코드, 소비자가격, 선택 사양 내역이 클립보드에 깔끔하게 복사됩니다.
- **제품 설명서(PDF) 연동**: 모델별 공식 매뉴얼 다운로드 링크를 제공합니다.
- **반응형 디자인**: PC 모니터뿐만 아니라 태블릿과 모바일 스마트폰 화면에서도 최적화되어 작동합니다.
